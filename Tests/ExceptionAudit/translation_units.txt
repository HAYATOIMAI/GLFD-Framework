# NOTE: saved WITHOUT a BOM on purpose. cmd.exe's `for /f` hands the BOM to the
# first line, so a leading `#` stops being the first character and the header
# is parsed as a row. The BOM rule is for source files that a compiler reads.
# Real translation units from Source\, audited as themselves.
#
# A probe can only audit what it can compile: templates and inline functions.
# A function defined in a .cpp is an external symbol from everywhere else, so no
# probe can see inside it. SceneManager is the example - every probe row for it
# is CLEAN while the row below says THROW.
#
# format:  <path from repo root>|<EXPECT>|<why, one line>
# EXPECT:  CLEAN | C4530 | THROW | C4530+THROW | NOCODE
# lines starting with # are ignored. no spaces around the separators.
#
# N-2 is about the per-frame path. A throw at construction time is a different
# question, and the WHY column has to say which one a row is - otherwise the
# list becomes a pile of accepted red that nobody reads.
